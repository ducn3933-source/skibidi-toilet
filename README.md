# Udemy UI Demo — Nhóm 8

Website minh họa cho bài tập lớn phát triển hệ thống học trực tuyến Udemy.

## Chạy thử trên máy
1. Tải hoặc giải nén toàn bộ các file.
2. Mở `index.html` bằng trình duyệt.

## Đưa lên GitHub Pages
1. Đăng nhập GitHub và tạo repository mới, ví dụ `udemy-nhom8`.
2. Chọn **Add file → Upload files**.
3. Tải lên `index.html`, `style.css`, `script.js` và `README.md` (có thể kéo cả 4 file vào).
4. Nhấn **Commit changes**.
5. Vào **Settings → Pages**.
6. Ở **Build and deployment**, chọn **Deploy from a branch**.
7. Chọn branch `main`, folder `/(root)`, nhấn **Save**.
8. Đợi GitHub xuất bản, sau đó mở đường dẫn hiển thị trong mục Pages.

## Chức năng bản demo
- Tìm kiếm và lọc khóa học theo danh mục.
- Sắp xếp theo giá hoặc đánh giá.
- Thêm/xóa khóa học trong giỏ hàng.
- Khu vực “Khóa học của tôi” dạng mô phỏng.
- Biểu mẫu đăng nhập/đăng ký mô phỏng.
- Giao diện giảng viên giới thiệu dạng mô phỏng.
- Giỏ hàng và khóa học được lưu trong `localStorage` của trình duyệt.

## Giới hạn
Đây là website tĩnh. Không có máy chủ, cơ sở dữ liệu dùng chung, đăng nhập xác thực, thanh toán thật, phân quyền bảo mật hoặc tải video lên máy chủ. Không nhập mật khẩu thật vào bản demo.
